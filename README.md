# regisseur (r7r)

Lightweight AI agent orchestrator.

Regisseur is an open source orchestration layer for agent-powered work, centered on tasks, workflow graphs, schedules, adapters, and run tracking.

This repository uses a `pnpm` workspace with shared packages in `packages/` and runnable apps/examples in `apps/`.

The project is currently at the initial scaffold stage. Core orchestration logic is not implemented yet.
